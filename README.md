## 🚨 The Problem

Insider threats account for **34% of all data breaches** (Verizon DBIR 2024). Unlike external attackers, insiders already hold authorized access — making them invisible to traditional perimeter defenses like firewalls and IDS.

XGuard addresses this by modeling normal employee behavior and flagging anomalous patterns before damage occurs — with every alert fully explained.

---

## 🎯 Key Features

### 🔍 1. Behavioral Anomaly Detection
- Analyzes employee behavioral logs (`employee_logs.csv`)
- Detects deviations from normal activity baselines
- Trained Random Forest classifier with a pre-fitted scaler (`model.pkl`, `scaler.pkl`)

### 📊 2. Risk Score Prediction
- Continuous risk score (0–100) per employee
- Results stored in `results.csv` for audit trail
- Threshold-based classification: Low / Medium / High / Critical

### 🧠 3. Explainable AI (XAI) Alerts
- Dedicated `explainer.py` module for SHAP-based decision explanations
- Every flag tells the analyst *which behaviors* drove the risk score
- Reduces alert fatigue by providing context, not just verdicts

### 📄 4. Automated PDF Incident Reports
- `report.py` generates per-employee incident reports automatically
- Sample outputs included: `report_Ashley_Flores.pdf`, `report_Test_Employee.pdf`
- Designed for HR, Legal, and CISO review workflows

### 📈 5. Interactive SOC Dashboard
- `dashboard.py` — Streamlit + Plotly powered interface
- Real-time risk visualization, employee threat timelines, anomaly breakdowns
- Cybersecurity-themed UI for SOC analyst workflows

### 🗃️ 6. Synthetic Data Generation
- `data_generator.py` — generates realistic employee behavioral datasets
- Enables testing without real organizational data
- Simulates normal vs. malicious insider activity patterns

## 🧠 How It Works

```
Employee Behavioral Logs (employee_logs.csv)
                ↓
        data_generator.py
    (Synthetic data generation)
                ↓
        train_model.py
  (Random Forest training + scaler fit)
    → model.pkl + scaler.pkl saved
                ↓
        explainer.py
   (SHAP explanation per prediction)
                ↓
    Risk Score (0–100) → results.csv
                ↓
        report.py
  (PDF incident report generation)
                ↓
        dashboard.py
  (Streamlit SOC Dashboard + Plotly viz)
```

## 📊 Dataset & Features

XGuard uses a synthetic behavioral dataset generated by `data_generator.py`, modeled after real insider threat behavioral indicators.

| Feature | Description |
|---|---|
| `login_hour` | Hour of day the employee logged in |
| `after_hours_access` | Access outside standard working hours |
| `files_accessed` | Number of sensitive files accessed |
| `emails_sent` | Volume of outbound emails |
| `usb_events` | Removable media usage count |
| `failed_logins` | Consecutive failed login attempts |
| `peer_deviation` | Behavioral deviation vs. peer group baseline |

## 🚀 Getting Started

**1. Clone the repository**
```bash
git clone https://github.com/Jagan83411/XGuard-Insider-Threat-Detection.git
cd XGuard-Insider-Threat-Detection
```

**2. Create virtual environment**
```bash
python -m venv venv
venv\Scripts\activate        # Windows
source venv/bin/activate     # macOS/Linux
```

**3. Install dependencies**
```bash
pip install -r requirements.txt
```

**4. Generate synthetic data (optional)**
```bash
python data_generator.py
```

**5. Train the model**
```bash
python train_model.py
```

**6. Launch the dashboard**
```bash
streamlit run dashboard.py
```

## ⚠️ Limitations

- Trained on synthetic data — real deployment requires retraining on org-specific behavioral baselines
- No live SIEM integration (Splunk / Microsoft Sentinel) yet
- Single-user scope — no multi-tenant or RBAC support currently
- PDF reports not digitally signed — additional tooling needed for legal proceedings
